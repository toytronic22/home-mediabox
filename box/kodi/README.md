# Правки Kodi

## Главный экран — один список вместо пяти

Скин Estuary по умолчанию показывает на главном экране до пяти рядов одних и тех же
фильмов: «Непросмотренные», «Случайные», «Жанры», «Начатые», «Коллекции» — плюс
столько же для сериалов. На небольшой библиотеке это одно и то же по кругу.

`Home.xml` кладётся в
`/data/user/0/org.xbmc.kodi/cache/apk/assets/addons/skin.estuary/xml/Home.xml`
(владелец `u0_a84:u0_a84_cache`, права 600). Оставлен один ряд с полным списком:
`videodb://movies/titles/` и `videodb://tvshows/titles/`, заголовки «Фильмы» и «Сериалы».
Ряд категорий убран настройкой `home_no_categories_widget=true`.

**ВАЖНО:** после правки проверять XML на валидность до отправки — Kodi при ошибке разбора
показывает чёрный экран. Проверка: `python3 -c 'import xml.etree.ElementTree as ET;
ET.fromstring(open("Home.xml").read())'`. Резервная копия рядом с файлом на приставке
(`Home.xml.bak-*`), в крайнем случае файл восстанавливается переустановкой скина.

## Библиотека — только то, что на винте

Раньше в библиотеке висели записи с сетевого диска ноутбука (`smb://…`),
который обычно выключен, — и его фильмы показывались как «непросмотренные», хотя открыть
их нельзя. Убрано: источники в `sources.xml`, пароль в `passwords.xml`, путь в базе
(`DELETE FROM path WHERE strPath LIKE 'smb://%'`). Осталось два источника — Фильмы и
Сериалы, оба с винта.
